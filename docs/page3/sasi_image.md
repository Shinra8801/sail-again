# PC-88VAのSASIディスクイメージ

ディスクの物理フォーマットは次のとおりです。

* シリンダ数
  * 615
* ヘッド数
  * 8
* セクタ数
  * 33
* セクタサイズ
  * 256

論理フォーマットは次のとおりです

```
論理セクタサイズ 1024 400h
論理セクタ数/クラスタ 10h
FAT ID  D3h

論理セクタ番号  用途                  論理セクタ数
-------------- -------------------- -----------------
+0             予約セクタ(IPL)       1
+1             FAT1                 4
+5             FAT2                 4
+9             ルートディレクトリ     96 (60h)
+105 (69h)     データ領域            39488 (9A40h)      ※ 論理セクタ数は次の式より求まる: (9A5h-1) * 10h
+39593 (9AA9h) 余り                  7
+39600 (9AB0h) (終端+1)
```
