# Jekyllとは

Jekyll は静的サイトジェネレーターです。

Markdown で記述した文書から HTML を生成できるため、ブログやドキュメントサイトの作成によく利用されています。

GitHub Pages では標準で Jekyll が利用できるため、サーバーを用意しなくても静的 Web サイトを公開できます。
