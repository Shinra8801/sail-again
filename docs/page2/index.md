# GitHub Pagesとは

GitHub Pages は GitHub が提供する静的 Web ホスティングサービスです。

HTML、CSS、JavaScript のほか、Jekyll を利用したサイトも公開できます。

個人サイトや技術文書、OSS プロジェクトのドキュメントなど、多くの用途で利用されています。
